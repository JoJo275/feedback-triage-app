# Tool Templates

This directory keeps a single reusable template for documenting tools listed in [../tooling.md](../tooling.md).

## How to Use

1. Copy [general-template.md](general-template.md) when you are ready to create a tool-specific page.
2. Rename the new file for the target tool.
3. Fill in all TODO fields with repo-specific details.
4. Keep ownership and boundaries explicit to avoid overlap with other tools.
