# CSS Conventions

This page tracks active CSS conventions used in this project.

## Working Rules

- Keep design tokens and component vocabulary aligned with the v2 CSS spec.
- Prefer documented `sn-` component naming and utility-first patterns.
- Treat generated CSS artifacts as build output, not hand-edited source files.

## When Changing CSS Conventions

1. Update the canonical spec first.
2. Update impacted templates/components.
3. Sync this page if the rule set changed.
