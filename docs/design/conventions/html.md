# HTML Conventions

This page tracks active HTML conventions used in this project.

## Canonical Sources

- [v2 UI spec](../../project/spec/v2/ui.md)
- [v2 accessibility spec](../../project/spec/v2/accessibility.md)
- [Frontend conventions notes](../../notes/frontend-conventions.md)

## Working Rules

- Use semantic tags for structure and interaction before generic wrappers.
- Ensure every form input has an associated label and accessible name.
- Keep heading structure sequential and include a skip-link target on page shells.

## When Changing HTML Conventions

1. Update the canonical spec first.
2. Update affected templates/pages.
3. Sync this page if the rules changed.
